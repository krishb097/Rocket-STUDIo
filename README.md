# 🚀 Roket STUDIo — Next-Gen Entertainment Hub & AI

**Roket STUDIo** is a modern, high-performance web application designed for entertainment lovers. It brings together Movies, Songs, TV Shows, Dramas, Analyses, and Reviews into a unified, cinematic interface powered by **Gemini AI Technology** and **Firebase Authentication**.

---

## ✨ Key Features

* 🎬 **Universal Search Engine:** Search for Movies, TV Shows, Tracks, and Dramas using live data feeds (OMDb & iTunes Search API integration).
* 🎵 **Live Audio Preview:** Listen to 30-second audio previews directly on song search results.
* 🤖 **RSIo AI Assistant:** Integrated AI redirection system powered by Google Gemini to help users discover legal streaming and download sources.
* 🔐 **Real Firebase Authentication:**
  * 🌐 **Google OAuth 2.0:** Single-click sign-in via Google Popup.
  * ✉️ **Email & Password Authentication:** Complete registration flow with automatic email verification links.
* 🎨 **Cinematic UI/UX:** Dark-themed ambient glow background, glassmorphism card layouts, interactive rating stars, and custom popup modals.
* ⌨️ **Smart UX Enhancements:** Search suggestions (search tails) dropdown and direct `Enter` key search access.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Grid/Flexbox, Custom Animations, Glassmorphism), JavaScript (ES6+ Modules)
* **Backend & Auth:** Firebase Authentication (v10 SDK)
* **APIs Used:**
  * OMDb API (Movie Data & Plot Details)
  * iTunes Search API (Music, Audio Previews & Media Artwork)
* **AI Integration:** Google Gemini AI
